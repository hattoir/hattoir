## 🤖 Featured Projects

### 🐍 Serpens

家庭内で人と暮らすことを目指して開発している、
蛇型の多関節ペットロボットです。

機械設計、電子回路・基板、センサ、ROS 2、
シミュレーション、AIを横断しながら開発しています。
